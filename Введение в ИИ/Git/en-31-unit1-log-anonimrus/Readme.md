	1 -- сдал;

2. Создайте массив с результатами, со случайными числами внутри 0 или 1 (равномерное распределение).
3. Случайным образом (равномерное распределение) распределите часы подготовки:
	если 0, то случайно выберите число от 0 до 39, после чего умножьте его на 0.25 
(чтобы все измерялось в четвертях часа)

	если 1, то случайно выберите число от 30 до 79, после чего умножьте на 0.25
